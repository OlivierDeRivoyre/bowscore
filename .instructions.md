# BowScore Repository Instructions

## Project Purpose
BowScore is a progressive web application (PWA) for tracking and managing archery scores. It provides a basic web interface for recording and managing archery game scores.

## Technology Stack
- **Frontend**: HTML5, CSS3, vanilla JavaScript
- **Architecture**: Progressive Web App with Service Worker
- **Files**:
  - `app.js` - Main application logic
  - `index.html` - User interface
  - `styles.css` - Styling
  - `sw.js` - Service Worker for offline functionality
  - `manifest.json` - PWA configuration

## Application Views
The app has 4 main views:

1. **Main Page** - Welcome screen with two buttons:
   - Create New Session
   - View History

2. **Setup Page** - Configuration form for starting a new archery session:
   - Distance selection (10m, 15m, 18m, 20m, 25m, 30m, 40m, 50m, 60m, 70m)
   - Target Size selection (60cm, 80cm, 120cm)
   - Starts a new scoring session

3. **Score Page** - Input form for recording archery scores:
   - Displays session info (distance and target size)
   - 6 series inputs (0-60 points per series)
   - Saves the complete session

4. **History Page** - View and manage past sessions:
   - Display of all saved sessions
   - Filter by distance
   - Filter by target size
   - View/edit/delete session functionality

## Key Features
- Offline-first capability via Service Worker
- installable as a standalone app
- Responsive web design

## Development Guidelines
When assisting with this project:
1. Maintain PWA compatibility and offline-first design
2. Keep the codebase simple and focused on core scoring functionality
3. Ensure accessibility and responsive design
4. Test Service Worker functionality
5. Validate manifest.json configuration

## Code Style
- Use vanilla JavaScript (no frameworks required)
- Keep components modular and maintainable
- Add comments for complex logic
